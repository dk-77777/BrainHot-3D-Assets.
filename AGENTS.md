# BrainHot Mining — art production rules

The user rejected the V01 pickaxes because they shared a common main structure. Each pickaxe must have its own silhouette, head, shaft or strongly adapted shaft, core, ornaments, materials, theme, aura and rarity reading. Recoloring, material swaps and small surface changes are insufficient. Shared geometry utilities are allowed; sharing a main head/shaft recipe across the collection is not.

The current pickaxe scope is only P01, P05, P06, P12 and P16. The user explicitly instructed: “Não avance para as 28 picaretas até que essas 5 estejam realmente distintas e aprovadas.” Do not resume the other 23 until the user approves these pilots or explicitly changes that scope. A passing technical test does not supply artistic approval.

Before modeling a pickaxe, document its silhouette, head, shaft, core, ornaments, materials and aura. Compare pilots without materials or effects; redesign any pair that reads too similarly.

Ores should be refined from existing models, with roughly 10–25% moderate size increase and stronger rock/crystal contrast, faceting, clusters and rarity progression. Preserve individual identities and previous versions for comparison; use V02 files for this revision.

Use actual bpy geometry. Reopen saved blends, round-trip GLBs, inspect meshes, transforms, pivots, dimensions and triangle counts, and inspect renders. Record limitations truthfully. Blender aura previews are not already implemented Roblox effects.

Do not modify the Roblox Studio project in this production task. The IDs in the production manifests are conceptual proposals; do not change functional IDs, drops, economy or saves.
