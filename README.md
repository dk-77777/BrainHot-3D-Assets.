# BrainHot Mining — 3D Assets

Repositório dedicado à criação e organização dos modelos 3D do jogo BrainHot Mining, desenvolvido no Roblox Studio.

## Ferramentas
- Blender
- Python (bpy)
- OpenAI Codex
- Roblox Studio

## Assets planejados
- 28 picaretas premium
- 24 minérios
- Portais temáticos
- Ovos colecionáveis
- Bases híbridas Halloween
- 14 Pets
- Aprimoramentos visuais dos Brainrots originais

## Direção artística
Stylized Premium / Realista Cartoon, com tema Halloween e fantasia.

## Objetivo
Modelar, texturizar, exportar e validar assets 3D otimizados para utilização no Roblox Studio.
